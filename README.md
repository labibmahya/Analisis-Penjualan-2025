# Analisis-Penjualan-2025
Analisis penjualan toko online 2025 menggunakan Excel: data cleaning, Pivot Table, Slicer, dashboard, dan rekomendasi bisnis. Data simulasi.

Proyek pribadi untuk latihan analisis data menggunakan Microsoft Excel.
Data adalah simulasi (fiktif), bukan data usaha nyata.

## Tujuan
Mengetahui performa penjualan, produk dan kota terbaik, serta pola
musiman, lalu menurunkannya menjadi rekomendasi bisnis.

## Alat
Excel: Table, SUMIFS, COUNTIFS, IF, PROPER, TRIM, Pivot Table,
PivotChart, Slicer.

## Alur kerja
Data mentah (512 baris) → Data bersih (500 baris) → Pivot → Dashboard → Insight

## Ringkasan data cleaning
12 duplikat dihapus, nilai usia tidak wajar dikosongkan, format tanggal,
gender, dan nama kota diseragamkan, nilai Quantity negatif dikoreksi dan
ditandai. Semua keputusan dicatat di lembar Catatan_Cleaning.

## Temuan utama
- Omzet melonjak pada November-Desember (sekitar 35% omzet setahun)
- Rumah Tangga dan Elektronik menopang sekitar 50,5% omzet
- 18,8% pesanan dibatalkan atau dikembalikan

## Keterbatasan
Data hanya satu tahun, tanpa biaya (yang dianalisis omzet, bukan laba),
dan merupakan simulasi.

## Rencana pengembangan
Menulis ulang analisis dengan SQL dan membangun dashboard di Power BI
(masih tahap belajar).
